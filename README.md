# OneChief OS 医疗创业驾驶舱（MVP）

本仓库用于落地「先闭环、后平台化」的一人公司智能体 WebApp：

> 先做 **AI总管 + 开发值班员 + 产品货架** 三件套，优先跑通 30 天内可变现闭环。

## 目标

把「推文/临床痛点/院内需求/患者问题/产品想法」自动加工成：

1. 商业判断
2. 产品设计
3. 技术方案
4. 合规判断
5. 开发任务
6. 商品化输出

## 7天 MVP 范围（v0.1）

### 5 个核心页面

1. 灵感录入页
2. 产品机会评分页
3. Agent 拆解页
4. 开发任务页
5. 产品货架页

### 8 个核心 Agent（顺序调用即可）

1. 总管 Agent
2. 产品经理 Agent
3. 技术架构 Agent
4. 医疗合规 Agent
5. 商业化 Agent
6. 内容营销 Agent
7. 开发提示词 Agent
8. 复盘 Agent

### 评分模型（100分）

- 痛点强度：20
- 付费意愿：20
- 7天MVP可行性：15
- 合规风险可控性：15
- 可复制性：15
- 资源匹配度：15

判定：

- `>=80`：立即开发
- `60~79`：进入验证池
- `<60`：暂不开发

## 首个变现闭环（30天）

建议首个产品：**体检报告解读 + 风险评估 + 私域转化**

MVP 必须项：

- 报告上传（PDF/图片）
- OCR（可先模拟）
- 指标结构化
- AI 解读
- 风险分层
- 医生审核入口
- 报告 PDF 导出
- 微信咨询二维码
- 后台客户列表

## 技术栈建议

- 前端：Next.js + Tailwind + shadcn/ui
- 后端：FastAPI + PostgreSQL + Redis
- AI 编排：提示词模板 + 工作流状态表 + API 调用
- 部署：Docker Compose + Nginx + 腾讯云轻量服务器

## 里程碑

### Day 1

- 生成项目骨架（前后端、数据库、Docker）

### Day 2-3（只验收4件事）

1. 灵感录入
2. AI分析
3. 机会评分
4. 自动生成开发任务

### Day 4-7

1. 产品货架
2. 开发值班员
3. 提示词模板库
4. 体检报告解读入口

### Week 2

- 用真实案例压测（体检报告、国际转诊、营养平衡、灰指甲助手、肺癌筛查、结直肠护理）

### Week 3-4

- 做演示版 + 对外试卖 + 收首个付费/试点客户

## 验收指标（是否继续投入）

1. 是否每天愿意打开使用
2. 是否显著减少整理提示词与盯开发时间
3. 是否能自动把想法转为任务
4. 是否形成可售产品货架
5. 是否在30天内出现首个付费或试点客户
